# YouTube Downloader

A modern desktop YouTube downloader built with Python and Tkinter.

## Features
- Paste a YouTube URL
- Choose save location
- Download video or audio
- Simple and clean interface
- Built-in file sanitization and error handling

## Requirements
- Python 3.9+
- Tkinter (usually included with Python)

## Installation

```bash
pip install -r requirements.txt
python app.py
```
